# PP6 - Classificador de Gats i Gossos

Projecte d'intel·ligència artificial que classifica imatges de gats i gossos mitjançant una xarxa neuronal convolucional (CNN).

## Tecnologies utilitzades
- Python
- TensorFlow / Keras
- Streamlit
- Google Colab

## Com funciona
1. El model s'ha entrenat amb el dataset `cats_vs_dogs` de TensorFlow Datasets
2. L'usuari puja una imatge a la web
3. El model prediu si és un gat o un gos amb un percentatge de confiança

## Fitxers del projecte
- `app.py` — aplicació web amb Streamlit
- `model_gats_gossos.json` — estructura del model
- `model_gats_gossos.weights.h5` — pesos del model entrenat
- `requirements.txt` — llibreries necessàries
